# Agro Forte & Sustentável 🌾💚

Este é um projeto de site institucional moderno focado no tema **"Agro Forte e Sustentabilidade"**. O objetivo da página é demonstrar como a tecnologia e as boas práticas ambientais podem caminhar juntas com a alta produtividade no campo.

## 🚀 Funcionalidades e Características

* **Layout 100% Responsivo:** O site se adapta perfeitamente a dispositivos móveis (smartphones), tablets e computadores comuns.
* **Menu Sanduíche:** Navegação otimizada para telas menores acionada por JavaScript interativo.
* **Design Moderno:** Utilização de sombras suaves, tipografia limpa, paleta de cores voltada à natureza (tons de verde) e imagens de alta definição via CSS.
* **Seções Completas:** Inclui áreas para Início (Hero banner), Pilares da sustentabilidade, Sobre a instituição e Rodapé informativo com redes sociais.

## 📁 Estrutura de Arquivos

* `index.html`: Toda a estrutura de conteúdo do site estruturada de forma semântica.
* `style.css`: Estilização visual, variáveis de cores CSS e regras de mídia (`@media`) para responsividade.
* `script.js`: Lógica do menu móvel de navegação.

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação)
* **CSS3** (Estilização e Grid/Flexbox)
* **JavaScript** vanilla (Interatividade básica)
* **FontAwesome** (Para os ícones de folhas, gotas d'água e redes sociais)

## 💻 Como executar o projeto

1. Salve os arquivos `index.html`, `style.css`, `script.js` e `README.md` na mesma pasta no seu computador.
2. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente em qualquer navegador web (Chrome, Edge, Firefox, Safari).
